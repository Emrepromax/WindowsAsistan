## 🚀 J.A.R.V.I.S Nedir?

**J.A.R.V.I.S**, Windows kullanıcıları için geliştirilmiş yapay zekâ destekli kişisel bir masaüstü asistanıdır.

Gemini Live altyapısı sayesinde gerçek zamanlı sesli sohbet sunar. Sistem kontrollerini gerçekleştirir, bilgisayarının durumunu takip eder ve günlük işlemlerini kolaylaştırır.

Modern arayüzü ve Türkçe desteğiyle bilgisayar deneyimini daha akıllı hâle getirir.

## ✨ Özellikler

| Özellik | Açıklama |
|:---|:---|
| 🎙️ **Gemini Live** | Gerçek zamanlı, doğal sesli sohbet |
| 🖥️ **Sistem Kontrolü** | Ses, parlaklık, kilitleme ve kapatma |
| 📊 **Sistem Durumu** | CPU, RAM, disk, pil ve ağ takibi |
| 🗺️ **Harita** | Konum arama ve trafik bilgileri |
| 🎧 **Hey J.A.R.V.I.S** | Sesli uyandırma desteği |
| 🔄 **Otomatik Güncelleme** | GitHub üzerinden sürüm kontrolü |
| 🇹🇷 **Türkçe Destek** | Türkçe komutlar ve sesli iletişim |

## 🛠️ Kullanılan Teknolojiler

- **Python 3.11** – Ana programlama dili
- **Gemini Live** – Gerçek zamanlı yapay zekâ ve sesli sohbet
- **Google AI Studio** – API anahtarı yönetimi
- **PyInstaller** – Windows EXE oluşturma
- **GitHub Releases** – Sürüm dağıtımı

## 📥 Kurulum

### 1. Depoyu indir

```powershell
git clone https://github.com/Emrepromax/WindowsAsistan.git
```

### 2. Proje klasörüne gir

```powershell
cd WindowsAsistan
```

### 3. Gerekli paketleri yükle

```powershell
pip install -r requirements.txt
```

### 4. J.A.R.V.I.S'i başlat

```powershell
python jarvis_ui.py
```

### 5. API anahtarını gir

İlk açılışta Google AI Studio üzerinden aldığın Gemini API anahtarını gir.

🔑 [Google AI Studio – API Key](https://aistudio.google.com/apikey)

## 🎮 Kullanım

| Tuş / Komut | İşlev |
|:---|:---|
| `F9` | Sesli sohbeti açar / kapatır |
| `ESC` | Pencereyi kapatır |
| `Sağ tık` | Ayarlar ve çıkış menüsünü açar |

## 🔄 Otomatik Güncelleme

J.A.R.V.I.S, GitHub Releases üzerinden yeni sürümleri kontrol eder.

Yeni bir sürüm yayınlandığında kullanıcıya güncelleme bildirimi gösterilir.

### Geliştirici için EXE oluşturma

```powershell
pip install pyinstaller

pyinstaller --onefile --noconsole --name JARVIS jarvis_ui.py
```

Oluşturulan EXE:

```text
dist/JARVIS.exe
```

Yeni sürümü GitHub Releases bölümüne yükleyerek dağıtabilirsin.
